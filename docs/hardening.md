# 远程访问设置指南

如果你只在家里的 Wi-Fi 下使用 Ting Reader，可以继续使用局域网地址，不必为了这份指南配置域名或 HTTPS。

如果你想在外面通过手机访问家里的书库，先确认自己使用哪种连接方式：

| 你的使用方式 | 需要做什么 |
|---|---|
| 只在家里访问，例如 `http://192.168.1.100:3000` | 修改默认密码，路由器不必开放 Ting Reader 的端口 |
| 通过飞牛远程连接访问 | 按飞牛连接流程登录，无需再为 Ting Reader 单独开放公网端口 |
| 通过自己的域名或内网穿透地址访问 | 修改默认密码，设置 HTTPS，并检查哪些端口和内容能被外部访问 |

## 先修改默认密码

新安装的实例默认账号是 `admin`，密码是 `admin123`。在开放远程访问之前，请先修改密码。

在 Web 页面中操作：

1. 登录 Ting Reader，进入 **我的**。
2. 在账号信息区域的 **修改密码** 中填写新密码。
3. 点击 **保存**，确认出现保存成功的提示。

给家人使用时，可以在 **用户管理** 中创建普通用户，并为他们分配需要访问的存储库。管理员账号留给安装插件、管理用户和调整系统设置时使用。

## 用自己的域名访问

这部分适用于自己配置域名、反向代理或内网穿透的用户。已经通过飞牛远程连接使用的用户可以跳过。

### 配置 HTTPS 地址

在 NAS、反向代理工具或穿透服务中，为 Ting Reader 配置一个 HTTPS 访问地址。

通常需要填写：

- **访问域名**：你准备使用的域名。
- **转发目标**：当前能正常打开 Ting Reader 的局域网地址和端口。
- **证书**：与访问域名对应的 HTTPS 证书。

例如，局域网访问地址为 `http://192.168.1.100:3000`，配置后在外面使用 `https://你的域名`。如果你修改过端口，或使用飞牛应用入口，请以实际访问地址为准。

配置完成后，用浏览器打开新地址，确认能正常登录，且没有证书错误；再把客户端中的服务器地址改为这个 HTTPS 地址。

如果出现证书警告，先检查访问域名与证书是否一致、证书是否过期。使用自签证书时，需要让设备信任对应的证书；不要把“忽略证书错误”当作所有连接问题的解决办法。

### 检查路由器和穿透设置

有了 HTTPS 入口后，检查是否还保留着直接访问 Ting Reader 端口的公网映射。例如，如果外部访问都走 HTTPS，通常不需要再把服务的 `3000` 端口单独开放到公网。

只开放需要的应用入口，不要把数据库、配置文件、日志目录或整个书籍文件夹设置为无需登录就能浏览、下载的公开目录。

## 提示“请求过于频繁”怎么办

Ting Reader 默认限制短时间内过多的登录等认证请求。遇到“请求过于频繁”或 HTTP 429 提示时，先稍等片刻再试，避免连续点击登录。

正常播放、封面加载和音频分段请求不计入这个登录限制，一般不需要修改。

只有确实需要调整时，才编辑服务实际使用的 `config.toml`。找到已有的 `[security]` 部分，修改下面几项，保存后重启 Ting Reader：

```toml
[security]
rate_limit_enabled = true
rate_limit_requests = 100
rate_limit_window = 60
```

这表示每个来源在 60 秒内最多发起 100 次认证请求。编辑时保留这一部分的其他设置，不要重复添加 `[security]`。

Docker 用户可以通过挂载配置文件或设置容器环境变量保存修改。避免只编辑容器内部的文件，否则重建容器后修改可能丢失。

如果你通过反向代理访问，且多人登录时经常一起遇到限制，可能是服务把所有请求都识别成了代理服务器。此时需要检查代理是否传递了真实来源地址，并在 `trusted_proxies` 中填写实际代理的 IP。不确定代理地址时，先查看部署工具的网络设置，不要直接照抄其他人的地址；Docker 中的代理地址也不一定是 `127.0.0.1`。

## 安装插件时看什么

优先从可信的插件商店或作者发布页获取插件。遇到未知开发者确认窗口时，先看发布者和请求权限，再决定是否安装。

特别留意插件是否需要读取文件、修改书籍，或访问任意网络地址。申请的权限应与你要使用的功能相符。

原生插件还会直接运行本地代码，安装前要确认作者和下载来源可信。不要只因为插件名称相同就认为来源相同。

## 分享链接、截图和日志前

播放链接、封面链接和外挂组件代码中可能带有登录令牌。带 `token=` 的完整链接不要发到群里、公开网页或问题反馈中；需要展示时，把令牌值遮住。

分享日志或截图时，也检查是否包含密码、飞牛访问码、Cookie 或网盘链接中的签名参数。外挂组件的使用和分享方式见 [外挂组件指南](widget.md)。

如果远程访问能登录，却不能播放 STRM，先确认手机当前网络能否访问实际音源。有些音源只有家里的 NAS 能访问，手机在外面无法直连；浏览器也可能限制部分音源的播放或拖动进度。可以尝试服务端转码，并记录具体失败的章节和提示，便于排查。

## 最后，用手机流量试一次

关闭手机 Wi-Fi，使用你准备长期使用的远程地址：

1. 登录普通用户，确认只能看到为其分配的书库。
2. 播放一本书，拖动进度，再切换下一集。
3. 如果使用 STRM、转码或插件，也分别试一次。
4. 确认访问 HTTPS 地址时没有证书警告。

最后，备份 Ting Reader 的数据目录、配置和插件目录；书籍源文件也应另行备份。使用项目默认 Docker Compose 时，对应宿主机的 `data`、`plugins` 和 `storage` 目录；其他部署方式以实际目录和挂载设置为准。备份应放在应用目录之外，避免重装或误删时一起丢失。
